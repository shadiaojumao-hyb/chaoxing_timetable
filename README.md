# 超星课表

基于学习通课程表构建的低网络要求且稳定的**移动端**课程表

## 如何使用

### 1.获取课程表链接

**1.手机版**📱
- 打开学习通
- 点击应用中心
- 寻找**学生课表**
- 进入后
   1. 出现课程✅：出现课程表后，点击右上角展开选项，再点击转发，点击复制链接
   2. 没有课程❌：很遗憾，学校不支持

**2.电脑版**💻
- 进入个人空间
- 右上角展开，点击**切换单位/角色**
- 确认后，主页会出现课程表
- 点击课程表右上角转发，复制链接

### 2.应用内导入
- 打开课表app
- 点击右上角第二个那个**输入链接**选项
- 粘贴进去刚刚得到的链接
- 如出现你的课程，恭喜成功
## 考试信息

顶部可切换“课程表 / 考试信息”。考试时间区域暂留空白；成绩区域支持内部横向、纵向滚动，点击放大可占满内容区，再点击缩小恢复上下等高布局。

首次进入时输入教务系统账号密码。成绩成功获取后保存到本机，切换页面和重新启动不会自动请求；点击右上角刷新才重新获取。密码及会话仅保留在内存中，重启后刷新或会话失效时需要重新登录。取消登录或刷新失败不会清空已有成绩。

成绩查询沿用 `教务系统成绩.py` 的动态密钥、登录表单和成绩接口，学期参数留空以查询全部可返回学期，并逐页读取。优先显示接口的文字成绩（例如“良”“中”）。

移动端直接连接教务系统；本地 Flutter Web 调试需要先运行 `dart run bin/chaoxing_proxy.dart`，为课表与教务系统提供跨域代理。
